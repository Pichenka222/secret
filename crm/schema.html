✨ Виртуальные поля (не хранятся в БД)
fullName
Возвращает lastName + firstName + middleName через пробел. Если ФИО не заполнено — возвращает username. Доступен через .toJSON() и .toObject().
age
Вычисляет возраст в годах на основе dateOfBirth. Возвращает null если дата рождения не указана. Учитывает прошёл ли день рождения в текущем году.
🔩 Middleware (Mongoose Hooks)
pre('save')
Хеширует пароль с помощью bcrypt (saltRounds=12) перед каждым сохранением. Запускается только если поле password было изменено (isModified check).
pre('findOneAndUpdate')
Автоматически хеширует пароль при обновлении через findOneAndUpdate, если поле password присутствует в объекте обновления.
methods.comparePassword
Метод экземпляра: сравнивает открытый пароль с сохранённым хешем через bcrypt.compare(). Используется при аутентификации.
